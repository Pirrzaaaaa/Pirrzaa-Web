# Portfolio Website — Premium Smooth Edition

Portfolio website modern dengan animasi fade yang super smooth, desain berkualitas, dan performa ringan (tanpa library berat, no lag).

## Cara Pakai

1. Ekstrak file `portfolio.zip`
2. Buka file `index.html` di browser apa saja (Chrome, Firefox, Edge, Safari)
3. Selesai — tidak perlu install apa pun

## Fitur

- Custom animated cursor (desktop)
- Smooth fade-in reveal via IntersectionObserver
- Parallax orbs mengikuti gerakan mouse
- Counter angka animasi
- Typed text effect
- Smooth scroll antar section
- Active section highlight di navbar
- Animated loader
- Fully responsive (desktop, tablet, mobile)
- Dark theme dengan gradient accent (ungu - pink - orange)
- Grid background subtle + glowing orbs
- Semua animasi GPU-accelerated (transform/opacity) agar 60fps

## Struktur

```
portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md
```

## Kustomisasi

- Ganti teks di `index.html`
- Ganti warna di `css/style.css` bagian `:root`
- Ganti phrases typed effect di `js/script.js` (array `phrases`)

Enjoy!
